Stratus ztC Edge 250i 產品資料整理

產品定位

Stratus ztC Edge 250i 是第二代 ztC Edge 邊緣運算平台，是一款安全、堅固且高度自動化的計算平台，專為企業網路邊緣、遠端工廠、分支據點與人力有限的現場環境設計。

它適用於 OT（操作技術）與 IT（資訊技術）場景，可協助企業在邊緣位置快速部署、管理與維護業務關鍵應用程式，降低停機風險，提升營運效率。

適用情境

ztC Edge 250i 適合部署於製藥、生技、食品與飲料、特殊化學品、石油與天然氣，以及其他工業領域。

在數位轉型過程中，企業網路邊緣會產生並處理越來越多資料，但現場環境可能惡劣、技術人力有限，傳統伺服器或工作站在部署、維護與防護上較不容易。ztC Edge 250i 的設計目標，就是讓企業能在邊緣環境中穩定運行重要應用程式。

主要優點

1. 更高效率
ztC Edge 250i 內建虛擬化功能，支援 Windows 與 Linux 客戶作業系統，可簡化關鍵邊緣應用程式的部署、管理與維護流程，降低現場人員負擔。

2. 簡化安全性
ztC Edge 250i 具備受限 USB 埠、安全通訊協議、受信任的啟動機制、基於角色的存取控制，以及易於配置的主機防火牆。即使沒有專職資安人員，也能協助保護邊緣運算平台。

3. 減少停機時間
ztC Edge 250i 具備自我監控、自我保護與自我同步功能，可降低非計劃性停機。系統更新可在運行中進行，降低計劃性停機時間。

4. 更高部署彈性
ztC Edge 250i 採用堅固、緊湊的工業設計，可部署於控制室、控制面板、車間或機器附近，適合無人值守站點或資源有限的遠端分散環境。

5. 簡化管理
ztC Edge 250i 提供 RESTful API，可與企業偏好的系統管理工具整合，簡化監控、管理與維護流程。

核心特色

簡化安全性
ztC Edge 250i 內建主機型防火牆、受限 USB 埠、與 Active Directory 整合的角色式瀏覽控制、安全通訊協議與受信任啟動機制，可降低邊緣運算環境的安全風險。

堅固冗餘節點
ztC Edge 250i 針對工業環境常見的惡劣條件設計，節點通過 UL Class I Div 2 認證，並達到 IP40 等級，適合部署在控制室、控制面板、車間或靠近資料產生設備的位置。相較於標準伺服器或工作站，更具耐用性與部署彈性。

工業互操作性
ztC Edge 250i 支援常見 OT 與 IT 協議，便於整合進既有工業自動化環境。可透過 SNMP 請求與陷阱設定通知和警報，也可透過 OPC UA 屬性或 RESTful API，將系統資料呈現在第三方管理工具或儀表板中。

現場可維護性
當 ztC Edge 250i 以冗餘對部署時，平台支援熱插拔與自動同步。現場人員可在節點仍運行時進行維護或修理，不需要重新啟動系統，有助於維持服務連續性。

內建虛擬化
ztC Edge 250i 搭載 Stratus Redundant Linux 操作環境，內含支援 Windows 與 Linux 客戶作業系統的虛擬化主機。它支援 OVF 文件與 OVA 映像，也支援第三方模板。直覺式管理控制台可協助本地或遠端人員設定、配置、匯入與管理虛擬機。

OT 與 IT 管理能力
ztC Edge 250i 內含 ztC Edge Console 管理工具，可協助管理員遠端瀏覽系統、設定閾值與警報、檢查更新、備份與還原系統設定，並管理虛擬機。管理員也可透過 RESTful API 與第三方系統管理工具整合，達到本地或遠端的集中監控與管理。

自動化保護
當 ztC Edge 250i 以雙節點冗餘部署時，資料會在平台間自動複製。若發生故障，虛擬機可在另一台機器上自動重新啟動或恢復。若系統偵測到網路或硬碟故障，也可自動重新路由流量或使用另一台電腦上的資料，減少人工介入。

高可用性與容錯

ztC Edge 250i 可透過雙節點部署啟用高可用性或容錯能力。

在高可用性配置中，若主節點故障，虛擬機可在次要節點重新啟動，降低停機影響。

在容錯配置中，系統可讓虛擬機在故障時恢復運作，並避免傳輸中或已儲存資料遺失。

服務與支援

Stratus ztC Edge 可搭配系統支援、系統健康附加功能與託管支援服務。這些服務可協助監控系統健康狀態，支援關鍵工作負載持續運行。

支援服務包含系統支援、進階零件交換服務、主動運行時間監控、警報分級、系統日誌審查、預測性故障分析、媒體保留服務、根本原因問題診斷、軟體更新與升級，以及安全瀏覽自助服務入口。

補充說明

ztC Edge 250i 可安裝於牆面或 DIN 導軌，採用無風扇固態設計。它適合需要更大儲存空間、更多處理能力，以及高可用性或容錯選項的大型軟體工作負載。

Stratus 其他邊緣運算平台

除了 ztC Edge，Stratus 也提供 ztC Endurance 與 ftServer。

ztC Endurance 可讓組織在邊緣或資料中心環境中運行關鍵應用程式，降低停機與資料遺失風險。

ftServer 是機架式容錯伺服器，適合執行更大規模的一級關鍵任務工作負載，支援 30 多個虛擬機，可提供不間斷的製造操作與集中控制應用程式。

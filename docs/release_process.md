# 系統版本與回復流程

這份後台目前採用 Git / GitHub 做程式碼版本控制，並用 `VERSION` 檔案記錄目前系統版本。

## 版本命名

- `v0.9.0`：目前開發中的穩定候選版本。
- `v1.0.0`：正式交付或正式上線版本。
- 小修正可用 `v1.0.1`、`v1.0.2`。
- 新功能可用 `v1.1.0`、`v1.2.0`。

## 每次發布穩定版

1. 確認本機測試沒有問題。
2. 更新 `VERSION` 檔案。
3. 更新 `data/admin_changelog.json`。
4. 將程式推上 GitHub。
5. 在 GitHub 建立對應版本標籤，例如 `v0.9.0`。
6. 到 VPS 拉取最新程式並重新啟動服務。

## 需要回到舊版本時

1. 先備份 VPS 上會變動的資料，例如 FAQ、KB、LOGS 與網站索引。
2. 切回指定 Git 版本或標籤。
3. 重新啟動服務。
4. 檢查 Dashboard、LOGS、知識管理與測試頁是否正常。

## 注意事項

程式碼可以用 Git 回復，但資料檔可能每天都在變動。回復版本前請先備份資料，避免新的 FAQ、KB 或 LOGS 被覆蓋。
